# Resume Assistant

一个基于 Vue 3 + Vite 7 的在线简历生成器，面向开发者和技术岗位求职场景。项目支持结构化编辑、实时 A4 预览、多套专业模板、头像上传、本地智能识别填充，以及 PDF / PNG 导出。

默认示例内容以 Java / Python 全栈开发工程师为方向，方便快速展示技术简历效果。

## 项目简介

Resume Assistant 是一个前端侧运行的 HTML 在线简历生成器。用户可以通过表单维护个人信息、教育经历、工作经历、项目经历、技能证书等内容，并在右侧实时查看简历排版效果。项目内置多种不同结构的简历模板，包括单栏、侧栏、时间线、卡片式和工程风布局，适合不同岗位和审美偏好的简历制作。

项目重点不是简单套用静态页面，而是将「简历数据」「模板布局」「A4 分页」「导出能力」拆分为可维护的前端工程结构，方便后续继续扩展模板、字段和导出能力。

## 功能特性

- 结构化简历编辑：个人信息、简介、教育、工作、项目、技能、证书。
- 实时 A4 预览：编辑内容后即时同步到简历页面。
- 多页简历支持：内容过多时自动拆分为多张 A4 页面。
- 多套专业模板：支持卡片式、侧栏式、时间线式、极简式等不同布局。
- 头像上传：支持本地图片预览并同步到简历。
- 本地智能识别：可从粘贴文本中提取姓名、岗位、电话、邮箱、城市和技能关键词。
- 导出 PDF / PNG：支持多页 PDF 导出，多页 PNG 会合并为长图。
- 单屏工作台：编辑区、预览区和模板区独立滚动。
- 响应式适配：桌面端优先，同时保留小屏纵向布局。

## 模板类型

当前内置模板：

- 青瓷卡片：清爽科技风，适合通用开发岗位。
- 夜航深色：时间线结构，适合经历较丰富的技术简历。
- 极简留白：克制排版，适合偏正式投递。
- 晨光渐层：卡片分区，适合产品型或综合型技术岗位。
- 石墨商务：深色侧栏，适合管理、架构或资深工程师。
- 竹影青绿：自然编辑式布局，适合运营技术、数据应用等方向。
- 钴蓝专栏：工程侧栏布局，适合后端、全栈、平台研发方向。

## 快速开始

建议使用 Node.js 20.19+。

```bash
npm install
npm run dev
```

启动后访问：

```text
http://localhost:5173
```

## 构建

```bash
npm run build
```

构建产物会输出到 `dist/`。

## 本地预览生产构建

```bash
npm run preview
```

## 核心模块

- `ResumeEditor.vue`：简历编辑表单，负责头像上传、字段编辑、技能和证书维护。
- `ResumePreview.vue`：简历预览、模板布局、A4 分页和页面 DOM 暴露。
- `TemplatePicker.vue`：模板选择面板。
- `data/resume.ts`：默认简历数据和模板配置。
- `types/resume.ts`：简历数据结构和模板类型定义。
- `styles.css`：工作台布局、模板视觉、滚动条和响应式样式。

## 导出说明

PDF / PNG 导出基于 `html2canvas` 和 `jsPDF`：

- PDF：按 A4 页面逐页导出。
- PNG：多页时合并为一张纵向长图。
- 导出过程在浏览器端完成，不依赖后端服务。
